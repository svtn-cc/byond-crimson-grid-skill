# byond-crimson-grid skill

Agent skill for BYOND/DM development in the crimson-grid project
(tgstation → DarkPack → Corvax, Vampire: the Masquerade V20).

Covers where code goes, how to change upstream files, how to write
player-facing text, and how to build and test in game through
[byond-mcp](https://github.com/svtn-cc/byond-mcp).

## Install

With the skills CLI (Node.js 22.20+), from the project directory:

    npx skills add svtn-cc/byond-crimson-grid-skill

Or by hand: copy `skills/byond-crimson-grid/` into your agent's skills
folder in the project, for example `.claude/skills/` or `.omp/skills/`.
